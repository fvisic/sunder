# Sunder Docs Site

This directory holds the MkDocs Material source for the Sunder guides site. To serve it locally, install the dependencies with `pip install mkdocs-material` and then run `mkdocs serve` from this directory - the site will be available at `http://127.0.0.1:8000` and reloads automatically as you edit any file under `docs/`. To produce a static build instead, run `mkdocs build`, which writes the rendered site to a `site/` directory. The configuration lives in `mkdocs.yml`, which sets the site name, the light/dark palette toggle, and the navigation tree; no external fonts or assets are loaded, so the site works fully offline.

Every guide under `docs/` follows the same page template contract: start with a single `#` H1 that states the page's subject in plain terms, follow it with one short paragraph that says what the reader will accomplish or understand by the end, then break the body into `##` sections ordered from the most common path to the more advanced or edge-case one. Use `admonition` blocks (`!!! note`, `!!! warning`, `!!! tip`) for callouts rather than bare bold text, use fenced code blocks with an explicit language for every command or config sample, and use a ` ```mermaid ` fence for any diagram instead of an embedded image. Cross-link related pages with relative Markdown links rather than absolute URLs so the site keeps working when served from a different path, and keep each page scoped to one topic - if a guide grows enough to need its own sub-navigation, split it into multiple pages under the same directory instead of stacking unrelated sections. Write everything in English, and use a plain "-" for a dash rather than an em dash.
